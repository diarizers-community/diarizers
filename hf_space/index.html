🎙️ Diarizers v1.0.1 — End-to-End Audio ASR, Speaker Diarization & DiarizationLM

End-to-end open-source (Apache-2.0 / MIT) pipeline combining Stage 1: Whisper ASR (WhisperWordASR), Stage 2: Neural Speaker Segmentation + Embeddings + Spectral Clustering (pyannote/segmentation-3.0 + speechbrain/spkrec-ecapa-voxceleb + Symmetric Normalized Laplacian SpectralClusterer), Stage 3: Word-to-Turn Alignment, and Stage 4: DiarizationLM-Gemma-4-E4B-v1 Post-Processing (Q4_K_M GGUF + Locality-Gated Transcript-Preserving Speaker Transfer LG-TPST).

💻 GitHub (diarizers-community/diarizers) 📦 PyPI (pip install diarizers==1.0.1) 🤗 Model: DiarizationLM-Gemma-4-E4B-v1 💬 Text-Only DiarizationLM-GGUF Demo 📄 DiarizationLM Paper (arXiv:2401.03506)
